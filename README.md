# Nippotica Corporation

Website for [Nippotica Corporation](https://www.nippotica.com) — a Tokyo-based deeptech venture builder.

Built with [Jekyll](https://jekyllrb.com/) using the [Sleek](https://github.com/janczizikow/sleek) theme.

## Business Units

- [Nippofin](https://www.nippofin.com) — Synthetic data and market signals for quantitative finance and insurance
- [Algotechniq](https://www.algotechniq.com) — Physical AI and computer vision systems for industrial applications on Nvidia platforms

## Local Development

```bash
bundle exec jekyll serve --livereload
```

## Deployment

Deployed via GitHub Pages on the `main` branch to [www.nippotica.com](https://www.nippotica.com).
